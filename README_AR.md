# مشروع SnaptAll لأندرويد

هذا ملف مشروع Android Studio أولي بواجهة عربية واتجاه RTL، لإضافة رابط واحد أو عدة روابط إلى قائمة.

## مهم قبل الاستخدام
- هذا المشروع **ليس APK جاهزاً**، ولا ينفّذ تنزيل الفيديوهات بعد؛ يلزم ربطه بمصدر تنزيل قانوني ومصرّح به أو واجهات المنصات الرسمية.
- لا توجد واجهة موحدة تتيح تنزيل أي فيديو من كل المنصات، كما أن تنزيل المحتوى الخاص أو تجاوز الحماية غير مدعوم.
- إزالة العلامة المائية ليست مضمونة، وتعتمد على المصدر والصلاحيات المتاحة.
- يطلب التطبيق إذن الإشعارات على Android 13 وما بعده عند التشغيل. أذونات التخزين القديمة غير مطلوبة هنا لأن الحفظ في المعرض لم تتم إضافته بعد.

## البناء
1. افتح المشروع في Android Studio على كمبيوتر.
2. انتظر مزامنة Gradle.
3. اختر Build > Build APK(s).
4. اختبر APK على جهازك قبل توزيعه.

## المرحلة التالية المطلوبة
تنفيذ Download Worker باستخدام WorkManager، وإضافة MediaStore لحفظ الملفات، ومشغل معاينة، ثم ربط كل منصة بمصدر تنزيل مصرح به. لا تضع مفاتيح API سرية داخل التطبيق.
